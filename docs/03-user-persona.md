# 03 — User Persona

> persona สมมติตัวเดียว ใช้อ้างอิงในตัวอย่าง ข้อมูลทดสอบ และการออกแบบ UI ทั้งโปรเจกต์ ถ้าจะเพิ่ม persona ต้องเปิด ADR

## "ต้น" — นักลงทุนรายย่อยหุ้นสหรัฐฯ
- พนักงานบริษัท ลงทุนหุ้นสหรัฐฯ ผ่านแอปโบรกเกอร์ ถืออยู่ 5–10 ตัว (เช่น TSLA, NVDA, RKLB)
- อ่านข่าวภาษาอังกฤษได้แต่ช้า มีเวลาดูข่าวช่วงเช้าก่อนทำงานและก่อนนอน
- ไม่ได้เทรดรายวัน ต้องการรู้ว่า "ข่าวช่วงนี้ของหุ้นที่ถืออยู่ไปทางไหน"

## สิ่งที่ต้องการ
1. เปิดหน้าเดียวแล้วเห็นทิศทางข่าวของหุ้นใน watchlist
2. อ่านสรุปสั้นแทนการอ่านข่าวทั้งหมด
3. ถามต่อได้ว่า "ทำไม" พร้อมลิงก์ข่าวต้นทาง
4. เห็นว่า sentiment ของข่าวสอดคล้องหรือสวนทางกับราคาปิด

## สิ่งที่ระบบจะ **ไม่** ให้
คำแนะนำซื้อขายหรือการทำนายราคา
