# 00 — Project Brief

> โจทย์ต้นทางที่โปรเจกต์นี้ถูกสร้างขึ้นมาตอบ — สรุปจาก [Project Proposal](assets/Project_Proposal_Stock_News_Sentiment.pdf) (ฉบับล่าสุด) เอกสารนี้เป็น **ต้นฉบับอ้างอิง** ถ้าเอกสารอื่นขัดกับ proposal ให้ยึด proposal และแก้เอกสารนั้น

**ชื่อโครงงาน:** ระบบติดตามและสรุปทิศทางความรู้สึกของข่าวหุ้นแบบใกล้เคียงเวลาจริง เพื่อสนับสนุนการติดตามข้อมูลของนักลงทุนรายย่อย (Stock News Sentiment)

**ประเภท:** Senior Capstone Project, Computer Science, Thammasat University

## สรุปหนึ่งย่อหน้า
โครงงานนี้พัฒนาระบบติดตามทิศทางข่าวหุ้นสหรัฐฯ แบบใกล้เคียงเวลาจริง บน Data Lakehouse (Amazon S3 + Apache Iceberg) ที่รองรับข่าวย้อนหลังหลายปีและข่าวใหม่ ณ ปัจจุบัน จำแนก sentiment รายข่าวด้วย FinBERT แสดงภาพรวมเทียบกับราคาปิดรายวันบนเว็บแอป และเพิ่ม LLM สรุปข่าวประจำวันกับ News RAG ที่ตอบคำถามจากข่าวจริงพร้อมแหล่งอ้างอิง

## ทำไมต้อง Data Lakehouse
ข่าวสะสมเพิ่มทุกวัน และต้องใช้ร่วมกันทั้งเว็บ การวิเคราะห์ และ LLM จึงต้อง
- เก็บข่าวดิบไว้ประมวลผลใหม่ได้เมื่อเปลี่ยนโมเดล
- ย้อนดูข้อมูล ณ เวลาก่อนหน้าได้ (time travel)
- ใช้ข้อมูลชุดเดียวกันได้หลายงานผ่าน SQL
