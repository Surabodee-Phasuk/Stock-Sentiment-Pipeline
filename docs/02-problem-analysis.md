# 02 — Problem Analysis

## ปัญหา
นักลงทุนรายย่อยที่ลงทุนหุ้นสหรัฐฯ ต้องติดตามข่าวจำนวนมากจากหลายแหล่งทุกวัน และต้องตีความเองว่าข่าวเป็นบวกหรือลบต่อหุ้นที่ถืออยู่ เครื่องมือที่มีอยู่มักแสดงข่าวเป็นรายการยาว ไม่สรุปทิศทางให้ หรือเป็นบริการเสียเงินสำหรับมืออาชีพ

| # | ปัญหา | ระบบตอบด้วย |
|---|---|---|
| P1 | ข่าวมาจากหลายแหล่ง ต้องเปิดหลายที่เพื่อติดตามหุ้นตัวเดียว | รวมหลายแหล่งข่าวลง Lakehouse เดียว แสดงในหน้า Stock Detail |
| P2 | มองภาพรวมไม่ออกว่าข่าวล่าสุดเป็นบวก กลาง หรือลบ | FinBERT จำแนกรายข่าว + ภาพรวมรายหุ้นรายวัน |
| P3 | ต้องอ่านและตีความเอง ใช้เวลาและต้องมีประสบการณ์ | LLM สรุปข่าวประจำวันพร้อมเหตุผล |
| P4 | อยากถามคำถามเกี่ยวกับข่าว แต่ไม่มีเครื่องมือที่ตอบจากข่าวจริงพร้อมแหล่งอ้างอิง | News RAG (Ask AI) |

## เทคโนโลยีที่มีอยู่และช่องว่าง
FinBERT จำแนก sentiment ข่าวการเงินได้อัตโนมัติ และ LLM สรุป/ตอบคำถามจากข่าวได้ แต่การใช้งานจริงต้องมีระบบข้อมูลที่ **รับข่าวต่อเนื่อง ตัดข่าวซ้ำ และเก็บข่าวดิบไว้ประมวลผลใหม่ได้** — นี่คือส่วนที่โครงงานต้องสร้าง

## สมมติฐานที่ต้องพิสูจน์
| # | สมมติฐาน | พิสูจน์ด้วย |
|---|---|---|
| H1 | ข่าว streaming และราคา batch อยู่ในตาราง Iceberg ชุดเดียวกันและ query ร่วมกันได้เร็วพอ | Athena query ≤ 5 วินาที |
| H2 | FinBERT แม่นพอสำหรับข่าวหุ้นจริง | Macro-F1 ≥ 0.70 บน 300 ข่าว |
| H3 | ผู้ใช้เข้าใจภาพรวม sentiment ได้เร็วจากหน้าเว็บ | SUS ≥ 68 |
| H4 | RAG ตอบได้ถูกต้องกว่า LLM ที่ไม่มี RAG | เทียบ 50–100 คำถาม |
