# ADR-0005: ข่าวภาษาอังกฤษเท่านั้น และราคาปิดรายวันเท่านั้น

**Status:** Accepted

## Decision
- ไม่เก็บโพสต์โซเชียล (X, Reddit, StockTwits)
- ไม่เก็บราคาระหว่างวัน ใช้ราคาปิดรายวันจาก Yahoo Finance ตั้งแต่ปี 2020
- หุ้นสหรัฐฯ ~50 ตัว (PoC 10 ตัว) ไม่รวมหุ้นไทยและคริปโต

## Consequences
เทียบ sentiment กับทิศทางราคาปิดเท่านั้น ไม่ทำนายราคาหรือแนะนำซื้อขาย
